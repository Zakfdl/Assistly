# مرحباً يا أبي — الإصدار 1.1

## الجديد

يمكن للدرس الواحد الجمع بين الأنواع الخمسة معاً، وكل قسم اختياري ومستقل:

1. تسجيل فيديو بالكاميرا أو اختيار فيديو محفوظ، ثم مشاهدته داخل الدرس.
2. التقاط صورة أو اختيارها، ووضع نقاط عليها وكتابة أو تسجيل شرح لكل نقطة.
3. تسجيل شرح صوتي عام أو اختيار ملف صوتي.
4. كتابة خطوات مرتبة.
5. إرفاق عدة ملفات مساندة مثل PDF وWord وExcel وفتحها بالتطبيق المناسب على الجهاز.

تظهر الأقسام كلها في نموذج إعداد واحد. إضافة الفيديو لا تحذف الصوت أو الصورة أو الخطوات أو المرفقات. ويمكن حذف كل وسيط أو ملف منفرداً. استبدال الصورة يحذف نقاطها المرتبطة بالصورة القديمة بعد التأكيد.

## الحفظ

- تُنسخ الوسائط الجديدة إلى ملفات خاصة بالتطبيق؛ لا تُخزن الفيديوهات بصيغة Base64 داخل localStorage.
- تُحفظ بيانات الدرس والمسودة في ملف بيانات ذري، وتبقى المسودة متاحة بعد إغلاق التطبيق وإعادة فتحه.
- عند فشل الحفظ لا ينتقل النموذج إلى رسالة نجاح ولا تُحذف المسودة.
- يتضمن التحديث نقل بيانات النسخة السابقة من عنوان الصفحة المحلي الأصلي، مع الاحتفاظ بالنص والصورة والصوت ونقاطها.
- التسجيل الصوتي يتوقف عند مغادرة التطبيق ويُضاف إلى المسودة إذا اكتمل حفظه.

الحدود الحالية: فيديو حتى 250 MB، صورة حتى 20 MB، ملف صوتي أو مساند حتى 50 MB، وحتى 20 ملفاً مسانداً في الدرس. التسجيل الصوتي المباشر حتى 10 دقائق. تشغيل صيغ الفيديو والصوت يعتمد على دعم Android/WebView لها؛ وفتح المستندات يتطلب تطبيقاً مناسباً لنوعها.

الدروس والوسائط محلية على الجهاز؛ اختيار أفراد العائلة لا يرسل الدرس إلى هواتفهم. حذف التطبيق أو مسح بياناته يزيل النسخ المحفوظة داخله.

## فتح المشروع

1. فك الأرشيف وافتح مجلد `HelloDad` الذي يحتوي على `settings.gradle.kts` في Android Studio.
2. اختر **JDK 17** من Settings > Build, Execution, Deployment > Build Tools > Gradle > Gradle JDK.
3. ثبّت Android SDK Platform 34 وBuild-Tools 34.0.0 من SDK Manager.
4. نفّذ Sync Project with Gradle Files ثم شغّل إعداد `app` على هاتف أو محاكي Android 7.0 أو أحدث.

الأرشيف يحتوي على Gradle Wrapper 8.2.1، ويستخدم Android Gradle Plugin 8.2.2 وKotlin 1.9.22. أُضيف AndroidX WebKit 1.10.0 لتحميل الواجهة والوسائط محلياً عبر أصل آمن.

للتحديث مع الاحتفاظ بالدروس الموجودة، استخدم نفس `applicationId` ومفتاح التوقيع السابقين، وثبّت كتحديث للتطبيق الموجود. رقم النسخة الجديد هو `versionCode = 2` و`versionName = 1.1`. لا يحتوي الأرشيف على مفتاح توقيع أو مسار SDK خاص بجهاز آخر.

## التحقق

نجح إنشاء APK للتجربة ونجحت اختبارات Android الخاصة بقراءة أجزاء الفيديو (3 اختبارات).

- 9 اختبارات لقواعد حفظ الدروس: اجتماع الأنواع الخمسة، إضافة الوسائط دون استبدال الأنواع الأخرى، الدروس التي تحتوي على فيديو أو ملفات فقط، إلغاء الاختيار، المحافظة على بيانات النسخة السابقة، وصوت نقاط الصورة.
- اختبار واجهة آلي عبر Chromium اجتاز: الأقسام الخمسة، درس يجمع كل المحتويات، تسجيل الصوت عبر محاكاة أحداث Android، حفظ المسودة واستعادتها، فشل الحفظ، إلغاء اختيار الفيديو، تشغيل فيديو فعلي في المتصفح، فتح المرفقات عبر الجسر التجريبي، وعرض الدرس في دور الأب. لم تُرصد أخطاء JavaScript أو تجاوز أفقي في العرض عند عرض 412 بكسل.
- اختبارات الواجهة تحاكي جسر Android؛ لا تثبت عمل الكاميرا والميكروفون ومشاهدي المستندات على هاتف فعلي. لم يجر اختبار على هاتف أو محاكي Android ضمن هذه المراجعة.

لتشغيل اختبارات قواعد الدروس: `node --test tests/model.test.cjs`.
اختبار الواجهة `tests/ui-smoke.cjs` يحتاج Playwright وChromium، ويمكن تحديد مسار المتصفح عبر `HELLODAD_BROWSER`.
اختبارات Android والبناء: `gradlew.bat assembleDebug testDebugUnitTest lintDebug` على Windows.
